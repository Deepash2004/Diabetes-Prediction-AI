Place your diabetes CSV here as data/diabetes.csv.

The project is designed for the common Pima-style dataset with these columns:
Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI,
DiabetesPedigreeFunction, Age, Outcome

A demo dataset generator is included, so you can test the full application
without manually finding a CSV. Run:
    python -m src.make_demo_data

For a resume project, replace the generated demo data with a documented,
publicly sourced dataset before publishing final metrics.
